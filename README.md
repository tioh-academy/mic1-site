# MIC1 starter site

## Fichiers
- index.html
- projects.html
- about.html
- styles.css

## Publication GitHub Pages
1. Crée un nouveau dépôt GitHub, par exemple `mic1-site`.
2. Dépose ces fichiers à la racine du dépôt.
3. Va dans Settings > Pages.
4. Choisis **Deploy from a branch**.
5. Sélectionne la branche `main` et le dossier `/root`.
6. Ton site sera publié sur `https://<username>.github.io/mic1-site/`.

## Important
- Ton site personnel principal (`<username>.github.io`) ne sera pas écrasé si tu utilises un dépôt différent.
- Ce dépôt sera un **project site** GitHub Pages.
- Pour faire disparaître automatiquement un projet complet, ajoute ensuite Supabase.
